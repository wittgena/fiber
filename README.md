# README
@about: The Universal Integration Boundary
@generator: gemini-3.1-pro
@topos: Hybrid Microkernel & Multi-dimensional Adapter Registry

Brane is a deterministic integration membrane. It standardizes state transfers, isolates external protocol volatility, and translates heterogeneous API payloads into native topological structures without circular dependencies. It operates through three strictly partitioned dimensional planes.

---

## Topos Dimensions

### `anchor` (Surface & Ingress Boundary)
The physical ingress layer. Normalizes external client requests, system bootstrapping, and multi-dimensional adapter binding.

* **`surface` (Registry & Spec):** Maps provider identities to structural adapters (`registry.adapter`). Executes lazy loading to prevent memory collapse. Defines explicit quarantine and resilience blueprints (`spec.gatekeeper`, `spec.security`).
* **`provider` & `inter` (Data Ingestion):** Replaces hardcoded conditional routing with a unified semantic regex/HTTP status pipeline (`mapper.exception`). Manages direct ingestion from file systems and GitHub repositories (`readers`).
* **`cli` (Ignition):** Controls core system bootstrap (`cli.bootstrap`) and manages Brane infrastructure services (Gateway, PyPI Membrane, MCP Clients) via `proxy.manager`.

### `bound` (Transport, Adapter & Routing Layer)
The structural translation and orchestration plane. Absorbs legacy dependencies (e.g., LlamaIndex, LiteLLM) and transduces them into Brane-native formats.

* **`channel` (Switch & Route):** Enforces a "strangler-fig" pattern (`switch.params`) to gracefully decouple external LLM dependencies at system ignition. Consolidates third-party namespace fragmentation (`compat.patch`).
* **`adapter` (Protocol & Middleware):** Translates MCP protocols securely, enforcing 5MB payload limits and strict ASGI authorization (`mcp.server.wrapper`). Maps Brane contexts directly into LlamaIndex topologies for spatial vector and completion translation (`inter.embedding`, `inter.llm`). Acts as a strict execution gatekeeper translating actions into LogicStreams (`bridge.ledger`).
* **`watcher` (Observation & Audit):** Topos-aligned phase observation loop (`sphere.observer`). Ingests Prometheus metrics into Universal Phase Snapshots (`prom.receptor`). Secures the outbound boundary using CPython Runtime Audit Hooks (PEP 578) with an immutable Merkle-backed store (`audit.warden`).
* **`transport` (Session):** Manages per-client connection state (`session.connection`) and StreamableHTTP asynchronous chunks via stateless/stateful standalone channels.

### `xphi` (Cognitive & Scope Manifold)
The state execution and proxy boundary. Orchestrates internal event flows, dynamically resolves execution schemes, and handles deterministic mock topologies.

* **`proxy` (Auth & Invocation):** Central authorization broker for the infrastructure (`auth.broker`, `auth.token`). Manages the `dphi.invoker` flow (`sense -> eval -> action -> listen -> reentry`).
* **`scope` (Deterministic Boundaries):** Generates standardized exceptions, vector embeddings, and completion payloads directly, isolating the system from external LLM dependency failures (`mock.exception`, `mock.completion`).
* **`loop` & `agent`:** Manages streaming data parsing, programmatic utilities, and dynamic resolution of internal/external execution schemes (`resolver.scheme`).
