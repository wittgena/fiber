# dphi 서비스 Public API 명세서

**대상 모듈:** `receptor.edge.public`
**개요:** 외부 에이전트의 HTTP 요청을 수신하는 무상태(Stateless) 인터페이스입니다. 자체적인 비즈니스 로직이나 DB 쓰기를 수행하지 않으며, 모든 요청에 대해 초기 검증(x402)을 마친 후 내부망으로 작업을 위임하고, 최종적으로 **`broker`를 통해 `dphi.wasm` 커널을 호출**하여 암호학적 상태 증명을 반환하는 역할에 집중합니다.

---

### 1. 에이전트 인텐트 단일 실행

* **Endpoint:** `POST /v1/public/agent/execute`
* **주요 역할:** 외부 에이전트의 코드(워크로드)를 내부 격리 환경에서 실행하고, 그 결과에 대한 상태 증명 영수증(AuditReceipt)을 반환합니다.
* **동작 방식:**
1. **검증 및 연산:** 결제 증명(`X-X402-Receipt`)과 페이로드를 내부망으로 전달해 서명 검증 및 샌드박스 내 코드 실행을 수행합니다.
2. **상태 지문 연산:** 연산 완료 후, 실행 결과와 소모 리소스 데이터를 바탕으로 **`broker`를 통해 `dphi.wasm` 커널을 호출**하여 결정론적 상태 지문(State Root)을 발급받습니다.
3. **결과 반환:** 다중 서명 합의 데이터와 커널 지문이 포함된 최종 실행 영수증을 클라이언트에 반환합니다.



### 2. OTLP 텔레메트리 로그 수집

* **Endpoint:** `POST /v1/public/telemetry/logs`
* **주요 역할:** 에이전트가 전송하는 OTLP 표준 로그를 수집하고, I/O 지연 없이 데이터 무결성 증명을 즉각적으로 발급합니다.
* **동작 방식:**
1. **데이터 추출:** 요청 페이로드에서 유효한 메트릭 데이터만 정제하여 추출합니다.
2. **동기식 증명 발급:** 빠른 응답을 위해 추출된 데이터를 **`broker`를 거쳐 `dphi.wasm`으로 전달**하고, 루트 핑거프린트 연산만 동기식으로 처리하여 즉시 반환(`200 OK`)합니다.
3. **비동기 위임:** 클라이언트 응답과 처리 흐름을 분리하여, 실제 데이터 저장은 내부 백그라운드 태스크로 위임합니다.



### 3. 감사 이벤트 단건 기록

* **Endpoint:** `POST /v1/public/audit/event`
* **주요 역할:** 민감한 감사 이벤트를 마스킹 처리하고, 해당 데이터의 원장 기록 여부를 수학적으로 증명(ZK)하여 반환합니다.
* **동작 방식:**
1. **데이터 정제:** 수신된 이벤트 데이터에서 민감 필드(PII 등)를 식별하여 암호화(Sanitization)합니다.
2. **상태 지문 연산:** 마스킹된 데이터를 **`broker`를 통해 `dphi.wasm`으로 전달**하여 상태 핑거프린트를 생성합니다.
3. **조건부 머클 증명 발급:** 클라이언트가 상세 증명을 요청(`verbose=true`)한 경우, **`dphi.wasm`의 머클 증명(Merkle Proof) 생성 기능**을 추가 호출하여 증명 데이터를 응답 본문에 포함합니다.
